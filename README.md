# Eventify 🎉

**Eventify** is event management backend system built with **Java Spring Boot**, featuring Liquibase.

## Features

- 🧪 Validations using Hibernate Validator
- 📦 RESTful API design with Swagger UI support
- 🧾 MySQL-based persistent storage
- 🛡️ Secure architecture using Spring Security

## 🛠️ Tech Stack

- Java 17+
- Spring Boot
- Spring Security
- MySQL
- Lombok
- Swagger/OpenAPI
- Maven
